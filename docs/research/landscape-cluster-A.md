# Chart Feature Landscape — Cluster A: charting leaders and professional desktops

Scope: **TradingView** (web Supercharts + desktop app), **Thinkorswim** (Schwab), **MetaTrader 5**, **NinjaTrader 8**, **Sierra Chart**, **Interactive Brokers TWS**, **Bloomberg Terminal**, **Koyfin**.
Purpose: feature inventory feeding the StockMind charting gap analysis.
Research date: **2026-10-01**. Research method: direct retrieval of official vendor documentation over HTTPS.

## 1. Methodology, and what "unconfirmed" means here

| Item | Detail |
| --- | --- |
| Retrieval | Every non-`unconfirmed` row below was read off a live official vendor page during this session (`curl` + HTML-to-text). The URL cited is the URL fetched. |
| Source preference | Vendor help centres / user guides only. No blogs, no forum posts, no review sites were used as the basis of any row. |
| `unconfirmed` | Means **not read in an official source this session**. It does not mean "absent". Several `unconfirmed` cells are features I would expect the platform to have; they are deliberately not asserted. A plausible invention is worse than an admitted gap. |
| "not in documented list" | Stronger than `unconfirmed`: the vendor publishes an enumerated list for that axis and the feature is **not in it**. Still not proof of absence, but it is evidence. |
| Published dates | Most vendor help pages carry no publication or revision date. Where a date is printed on the page it is recorded (IBKR prints one; MetaQuotes, TradingView and Schwab print only a copyright year). Dates are never guessed. |
| Counts | Where a vendor states a count, the vendor's number is used and attributed. Where a count was derived by counting documented entries (sitemap pages, reference-list bullets, table rows), the derivation is stated so the number can be re-checked. |
| Bloomberg Terminal | **No official Bloomberg page could be retrieved.** Every request to `bloomberg.com/professional/*` returned HTTP 403 this session, and terminal documentation (`HELP HELP`, `BU <GO>`) sits behind subscriber login. Consequently §9 asserts nothing. |
| Licensing | No source is quoted beyond short unavoidable UI labels and setting names. All descriptions are summaries. **Content was rephrased for compliance with licensing restrictions.** |
