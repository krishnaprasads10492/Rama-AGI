RĀMA AGI — GROUNDED ARCHITECTURE & IMPLEMENTATION MAP
This map was submitted for review against the codebase. It was accurate on every file name, function name, and constant checked. Two corrections were needed and are marked below — both are the same class of mistake the poster audit above exists to catch: an invented precision number, and a link between two systems implied by layout that doesn't exist in the code.

1. Security & Identity Layer

Three-Gate Authentication authCore.cjs
Argon2id password + 12-digit HMAC access key.
Local Vault cryptoCore.cjs
AES-256-GCM at rest, with a verifier that rejects a wrong passcode instead of silently returning an empty store.

2. Cognition & Routing Engine

Multi-Model Router modelRouter.cjs
Fallback chain: OpenAI → Anthropic → Gemini → Groq → Mistral → Ollama.
Tiered Cognition Ladder cognition.js
Reflex (no LLM) → Local open-weight → Cloud API.
"<5ms" reflex latency — never benchmarked, no timing code exists for this tier. Corrected: reflex means "no model call, no network round-trip" — a real property, not a measured number. Same mistake class as the poster's invented "27.2ms inference throughput," just smaller.

3. Genome & Instantiation Mesh

Holonic Multi-Instance Genome genome.cjs
30 genes / 8 domains, verified live against this machine.
Specialized Roles genome.ROLES
Strategic Enterprise Optimizer, R&D Agent, Cybersecurity Sentinel, Cultural Alignment & Wellness Advisor — full labels checked against source.
Resource Orchestrator resourceOrchestrator.cjs
Bounded CPU/RAM/thermal admission control. MAX_INSTANCES=8.

4. Governance & Code Evolution

Approval Ledger proposals.cjs
Single gate — no self-change without recorded master approval.
AST Static Verification verifyProposal.cjs
Code quality scoring and issue detection.
"before execution" — implies it gates sandboxEngine.cjs; it does not, they never call each other. Corrected: it runs before a file-write proposal is approved (self-modify / regen / evolution), not before sandboxed code execution. Two separate systems, wrongly linked by layout.
Sandboxed Execution sandboxEngine.cjs
Tiered, resource-admitted execution: SAFE / STANDARD / ELEVATED. Independent of the verification step above.
